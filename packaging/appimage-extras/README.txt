GameSir Cyclone 2 - AppImage
============================

FIRST TIME ONLY: install the udev rule. Without it the app cannot open the controller
("permission denied" or "controller not found").

  1. Make the files executable (a zip download loses that):
         chmod +x install-udev.sh GameSir-Cyclone-2-*.AppImage
  2. Run the installer (it asks for your password):
         ./install-udev.sh
  3. Unplug and replug the controller (or its 2.4G dongle).
  4. Start the AppImage:
         ./GameSir-Cyclone-2-*.AppImage

Afterwards you only need the AppImage. Needs a graphical session; no other install.

---------------------------------------------------------------------------------------

PREMIERE UTILISATION UNIQUEMENT : installez la regle udev. Sans elle, l'application ne peut
pas ouvrir la manette (« permission refusee » ou « manette introuvable »).

  1. Rendez les fichiers executables (le zip perd cette information) :
         chmod +x install-udev.sh GameSir-Cyclone-2-*.AppImage
  2. Lancez l'installateur (il demande votre mot de passe) :
         ./install-udev.sh
  3. Debranchez puis rebranchez la manette (ou son dongle 2,4 G).
  4. Lancez l'AppImage :
         ./GameSir-Cyclone-2-*.AppImage

---------------------------------------------------------------------------------------

SOMENTE NA PRIMEIRA VEZ: instale a regra udev. Sem ela o app nao consegue abrir o controle
("permissao negada" ou "controle nao encontrado").

  1. Torne os arquivos executaveis (o zip perde essa informacao):
         chmod +x install-udev.sh GameSir-Cyclone-2-*.AppImage
  2. Execute o instalador (ele pede sua senha):
         ./install-udev.sh
  3. Desconecte e reconecte o controle (ou o dongle 2.4G).
  4. Abra o AppImage:
         ./GameSir-Cyclone-2-*.AppImage
